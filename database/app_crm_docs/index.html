5 Features — Quick View

1. Punch IN — Morning Daily Plan

3 questions: Order amount (₹), Approval count, Project detail count. Minimum 1 mandatory. Order/Approval fill kare to Customer dropdown (assigned only, search).

2. Punch OUT — Evening Completion

Savare je plan fill karyo ae completion submit kariye vagar Punch OUT block. Actual achieved values submit karvana.

3. Visit Start — 19 Type Selection

Visit start karva pahela 19 ma thi 1 type select karvu mandatory. New Customer, MEP, Government, CPWD/PWD, Corporate, Developer, etc.

4. Visit Complete — 5 Yes/No Questions

Visit stop par: Order? Approval? Project details? Contract details? Payment?

5. PI/Quotation Submit Popup

Submit button par: Customer knows full product range? Na hoy to reason (No info / Price high / Need approval). Price high → High Rate form. Need approval → Consultant form.
